\Aphorism{s-179-p179-m001}{267}
Die Sonne schien blendend über einen Hügelsaum herüber; als ich das Auge schloss, sah ich erst, mitten im nachklingenden Sonnenbild, die Schattengestalt einer Palme, die mir vorher durch Irradiation unsichtbar geblieben war. So tritt ein Bild, ein Sinn, ein Ereigniss erst in der Nachwirkung hervor, wenn Glanz und Getöse der Wirkung nachgelassen; so kann man aus zweiter Hand von der Umwelt mehr empfangen als unmittelbar ihr zugewandt; so kann es nöthig sein, \Sperr{wegzusehen}, um mehr zu sehen.
