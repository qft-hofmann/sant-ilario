\Aphorism{s-117-p117-m003}{138}
Geständnisse und Intimitäten gar zu junger Menschen wirken peinlich; wie kann man ein Buch wie \Foreign{la nouvelle Héloïse} aushalten! Dieses ewige Zuviel von Saftfülle, Animalität, Rassen- und Geschlechtsaroma, dieser Geruch nackter, schwitzender, verliebter Seelen! Ohne eine Spur Alterung, Trockenheit, Kälte, Abstraction wird das Erotische völlig ungeniessbar.
