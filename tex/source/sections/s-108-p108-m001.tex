\Aphorism{s-108-p108-m001}{110}
Ohne einen Mitklang geschmeichelter Eitelkeit kann der Mann nicht lieben. Wer in das Leben eines Weibes tritt, will dort einen Neujahrstag oder wenigstens einen Monats-Ersten oder allerwenigstens einen Wochenbeginn, einen Sonntag bedeuten: um so mehr, wenn das Weib für ihn selber eine \Foreign{vita nuova} bedeutet.
